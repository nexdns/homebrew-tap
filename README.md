# NexDNS Homebrew tap

Homebrew casks for [NexDNS](https://nexdns.tech) tooling.

```bash
brew install --cask nexdns/tap/nexdns-cli
```

`nexdns-cli` is the command-line client for the NexDNS platform: zones, records,
DNSSEC, webhooks and DNS-as-Code from the terminal. Source and documentation are
in [nexdns/cli](https://github.com/nexdns/cli).

The cask in this repository is written by GoReleaser when a CLI release is
tagged. Edit it here and the next release overwrites it; fix the source instead.
